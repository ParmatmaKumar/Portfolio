# Parmatma Kumar — Developer Portfolio

A responsive personal portfolio built with React, Vite, and Tailwind CSS.

## Features

- Responsive navigation and single-page sections
- Intro, about, skills, services, project showcase, and contact form
- Dark visual theme with violet accents
- Contact form opens a pre-filled email in the visitor's email app (no server-side submission)
- Reduced-motion support and basic page metadata

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Before publishing

- Add the correct GitHub links and live demos for each project.
- Replace the LinkedIn link in `src/pages/Contact.jsx` with your actual profile URL.
- Add a resume PDF and a download link if you want a CV button.
- Keep credentials and API secrets out of the repository. Use environment variables for local secrets and ensure `.env` files are ignored by Git.
